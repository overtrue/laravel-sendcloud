# Changelog

- Require PHP ^8.3, Laravel ^13.30, and SendCloud SDK ^2.0.

- Add PHP 8.3–8.5 CI with latest and lowest secure dependency checks.
- Document SDK breaking changes and remove the unverified Octane compatibility badge.
